# RentRadar

## Project Objective

RentRadar is a rental property listing portal developed using Django and MongoDB. The application allows landlords to add and manage rental properties while enabling tenants to search properties based on area, city, and budget. It also provides rental price analysis through area-wise average rent reports and price trend visualization.

---

## Features

- Add rental properties
- Edit existing property details
- Delete properties
- Search properties by area
- Search properties by city
- Filter properties by maximum rent
- View area-wise average rent
- Price trend chart using Chart.js
- MongoDB database integration
- REST API for property listings

## Installation & Setup

### Clone Repository

```bash
git clone YOUR_GITHUB_LINK
```

### Move into Project

```bash
cd RentRadar
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

Windows

```bash
venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Server

```bash
python manage.py runserver
```

Open

```
http://127.0.0.1:8000/
```
